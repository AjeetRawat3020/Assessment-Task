# VIVCOS Digital Visiting Card

A responsive React + Vite digital visiting card created for the VIVCOS technical task.

## Run locally

```powershell
npm install
npm run dev
```

## Tailor before deployment

The app contains individual digital visiting cards for **Hemangi Singh**, **Lakshya Prabha**, **Madhusmita Mohanty**, and **Rutu Verma**. Use the employee selector to switch cards. The phone number, email address, employee ID, department, and location are intentional placeholder details for this demo.

- Employee portrait: `public/assets/rutu-verma.jpeg`
- Supplied company logo: `public/assets/vivcos-logo.jpeg`

The Call, WhatsApp, Email, Share, Copy Link, and website links are all implemented.
